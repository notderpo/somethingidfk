# Weekly board report

Create one issue titled `Board report - week <ISO week>`, assigned to the board, with this body:

```
## Decisions needed (max 3)
- <decision> - options A/B - recommendation - deadline

## Shipped last week
- <issue> - <one line> - <PR or file link>

## Blocked
- <issue> - blocked on <what/who>

## Next week (max 5)
- <issue> - owner - goal (G1-G4)

## Spend
| Agent | Spent USD | Budget USD | % |
Flag anyone above 80%. Note any run that cost unusually much and why.
```

Rules: under 300 words. No praise, no filler. If a section is empty, write "none".
