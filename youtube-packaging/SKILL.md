# YouTube packaging

File: `videos/<slug>/package.md`

```
## Titles (5 options, ranked)
1. <title> - why it works
## Thumbnail brief (2 concepts)
- Main visual (real-life imagery only), text (max 4 words, Barlow Black), emotion, colour accent
## Description
<first 2 lines = hook + promise, then summary, then sources list from research.md>
## Chapters
00:00 <name>
## Tags (max 10)
```

Rules:
- Titles under 60 characters, front-load the subject. Curiosity is fine; misleading is not. The video must pay off the title.
- Thumbnail text must not repeat the title.
- Chapters follow the script's section headings and timings.
- Sources in the description: the key primary sources from research.md.
